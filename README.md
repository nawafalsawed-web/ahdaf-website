# موقع أهداف — التصوّر الجديد

تصوّر تفاعلي كامل للصفحة الرئيسية لموقع [ahdaf.co](https://ahdaf.co)، مبني HTML/CSS/JS خالص بلا أي إطار عمل ولا حزم.

- **معاينة حيّة:** https://nawafalsawed-web.github.io/ahdaf-website/
- **نظام التصميم:** https://nawafalsawed-web.github.io/ahdaf-website/design-system.html

## التشغيل

ما فيه build ولا `npm install`. افتح `site.html` مباشرة، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000/site.html
```

الصفحة **بلا أي طلب خارجي**: الخط مضمّن في `assets/fonts`، ولا CDN ولا Google Fonts. تشتغل بلا إنترنت.

## البنية

```
site.html              الصفحة الرئيسية (كل الـCSS والـJS داخلها)
design-system.html     شيت نظام التصميم: الألوان والخطوط والمكوّنات والتوكنز
index.html             تحويلة إلى site.html (لـ GitHub Pages)
site-v1.html           النسخة الساكنة الأولى، للمرجع فقط
assets/
  tokens.css           مصدر الحقيقة الوحيد: الألوان، الخطوط، المسافات، الزوايا، الظلال
  fonts/               Saudi Serif بثلاثة أوزان (خط الموقع كاملاً)
  logos/               شعارات العملاء (١١ منها SVG أصلي)
  platforms/           شعارات منصات أهداف
  works/ cases/        صور الأعمال وأغلفة المقاطع
  avatars/             صور المؤثرين
  influencers.json     بيانات المؤثرين (محقونة داخل site.html كمصفوفة JS)
stitch-refs/           شاشات مرجعية ولّدها Google Stitch
```

## نقاط تهمّ المطوّر

**الألوان والخطوط كلها في `assets/tokens.css`.** أي تغيير في الهوية يبدأ من هناك وينعكس على الصفحتين.

**بيانات المؤثرين محقونة داخل `site.html`** كمصفوفة `INF` وليست `fetch` لأن المتصفح يمنع `fetch` على بروتوكول `file://`. عند الربط بباك إند، استبدل المصفوفة بنداء API وابقِ شكل الكائن كما هو:

```js
{ name, platform: 'snap'|'tiktok', url, handle, cat, img }
```

**الأقسام التفاعلية:**

| القسم | الآلية |
|---|---|
| البطل | شبكة نقاط وخطوط على `<canvas>` تتفاعل مع المؤشر |
| الخدمات | ألواح تتمدّد بالمرور (وبالضغط على الجوال) |
| الأعمال | معاينة صورة تتبع المؤشر، وعلى الجوال الضغط يفتح الصورة |
| المؤثرون | محور: زر مركزي + خيوط SVG متدلية + ٢٠ صورة تدور على ثلاثة مدارات |
| القائمة | لوحة فلترة + سلة ترشيح + بريف طلب ينتهي برسالة واتساب معبّأة |
| المنصات | صفّان متعاكسان من المستطيلات |
| المنهجية | خط عمودي يُرسم مع التمرير |

**RTL:** الموقع عربي أساساً مع زر تبديل للإنجليزية (كل نص فيه `data-en`). انتبه: خصائص `inset-inline-*` تنعكس في RTL، فالعناصر المحسوبة بالجافاسكربت (عقد المحور، معاينة الأعمال) تستخدم `left/top` الفيزيائية عمداً.

**الحركة:** كل الأنيميشن CSS أو `requestAnimationFrame`، ومحترم لـ `prefers-reduced-motion`.

## المقاطع

مستضافة على درايف وتُشغَّل داخل الصفحة عبر `iframe` من `drive.google.com/file/d/<id>/preview`. عند الإطلاق يُفضّل نقلها إلى استضافة فيديو حقيقية (Cloudflare Stream أو Bunny) للأداء.

## الملاحظات المفتوحة

- صور المؤثرين مسحوبة من حساباتهم العامة، تحتاج مراجعة حقوق قبل النشر الرسمي.
- نموذج التواصل وبريف الطلب واجهة فقط، يحتاجان ربطاً بباك إند أو بنظام أهداف الداخلي.
- الشعارات العالمية (كوكاكولا، أديداس…) من ويكيميديا للعرض في التصوّر، تحتاج إذن العميل قبل عرضها كمرجع عملاء.
